# html-editor-extension
它解决什么问题？
你有没有遇到过这些情况：

AI 帮你生成了一份精美的 HTML 演示文稿，但有一段文字写错了、有张图想换掉——找研发同事改？排队等半天；自己打开源代码？密密麻麻全是英文。
网页上有个错别字、有句话想换个说法，就改几个字，却不知道从哪下手。
改好的东西想发给同事看，又不想让人家装一堆软件。
「网页随手改」就是为这些时刻准备的：像改 Word 文档一样改网页，改完导出一个文件，谁都能打开。

能做什么？
✏️ 改文字 —— 点哪儿改哪儿
开启插件后，点击页面上的任何文字，直接打字修改。旁边的工具栏可以调整：

字号：调大调小，随心所欲
颜色：文字颜色一键换
行距：下拉框细调，排版更舒服
对齐：左对齐、居中、右对齐
🖼️ 换图/插图 —— 悬停就出现小工具条
鼠标悬停在图片上，出现小工具条：换图、插图、删除、复制，一目了然。

插入的图片支持拖动移动位置、四角拉伸调整大小
支持图片裁剪，还能选择压缩质量
同样支持插入视频，视频也能调整大小和位置
📦 移动模块 —— 整块挪走，排版不乱
页面里的文字模块、卡片可以整体拖动到新位置，插件会自动锁定宽度，不会出现挪完之后一行字变成两行的尴尬。

🎨 一键换主题色
点「主题」，插件自动分析页面配色，列出出现频率最高的 3 个主题色，每个都能单独替换成你想要的颜色。换个主色，整个页面气质就变了。

🔤 全局换字体
标题、正文分开选字体，内置中英文多种版权安全的系统字体，一键切换，告别千篇一律。

💾 改坏了也不怕
↩ 撤销 / ↪ 重做：随时反悔
草稿自动保存：没改完关掉了页面？重新打开，内容还在
原文件零影响：所有修改只在浏览器里进行，不动你的原始文件
📤 一键导出
导出 PDF：自动处理多页演示文稿，打印对话框里选「另存为 PDF」即可（记得勾选「背景图形」，不然背景色会丢失）
导出 HTML 副本：
页面不依赖本地资源 → 直接导出单个 HTML 文件
页面引用了 assets 文件夹里的图片/样式 → 插件会引导你选择原文件夹，然后二选一：
单文件模式：所有用到的图片、字体全部嵌进 HTML，一个文件发微信、发邮件，谁收到都能直接打开
完整文件夹模式：HTML + 资源文件整套导出到下载文件夹的子目录，结构与原来一致，适合资源较多的场合
怎么用？三步上手
开启：点击浏览器右上角的「网页随手改」图标——工具栏出现、角标亮起绿色圆点 ●，说明已开启；再点一下关闭。页面上方会提示当前版本号，方便确认用的是新版。
修改：点文字直接编辑；悬停图片出现工具条；底部工具栏调格式、换主题色、换字体。底部工具栏还能拖到顺手的位置，下次打开还在老地方。
导出：点「⬇ 导出副本」或「🖨 导出 PDF」，成品自动落到浏览器默认下载文件夹。
常见问题
Q：支持哪些浏览器？ Chrome（以及 Edge 等基于 Chromium 内核的浏览器）。以「开发者模式加载本地扩展」方式安装。

Q：会不会把我的原始文件改坏？ 不会。插件的所有操作都发生在浏览器里，原始 HTML 文件一个字节都不会动。改得不满意，关掉插件刷新页面就恢复原样。

Q：为什么打开本地 HTML 文件后插件没反应？ 本地文件（file:// 开头的地址）需要在扩展管理页勾选「允许访问文件网址」。

Q：导出的副本发给别人，对方需要装插件吗？ 不需要。导出的就是普通 HTML 文件（或文件夹），对方用任何浏览器双击打开即可。

Q：修改的内容是保存在哪里的？ 编辑期间自动存在浏览器本地（草稿机制）。点了「导出」之后草稿自动清空。注意：草稿按页面地址记忆，仅限本机浏览器。

技术小档案（给感兴趣的同事）
Chrome 扩展 Manifest V3，权限极简：activeTab、scripting、downloads——不读浏览记录、不收集任何数据，所有操作都在你的浏览器本地完成
单击开关按标签页独立控制，刷新页面自动复位
无需联网、无需注册、无需安装任何依赖
「网页随手改」——把改网页这件事，从"提需求等排期"变成"我自己动手，30 秒搞定"。
